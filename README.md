# Linux Administration Lab

## About the Project

This repository documents my practical learning journey in Linux system administration using Fedora Linux.

The main goal of this project is to develop practical skills in system configuration, user management, file permissions, network diagnostics and basic server administration.

## Environment

- **Operating System:** Fedora Linux
- **Shell:** Bash
- **Tools:** Linux Terminal, system administration utilities

## Skills & Topics

The project covers the following areas:

- Linux system information and monitoring
- User and group management
- File and directory permissions
- File system navigation and management
- Network configuration and troubleshooting
- Process management
- System logs analysis
- SSH configuration and remote access
