## EN

# Linux User and Group Management

## Objective
Practice Linux user and group administration, account management and access permissions.

## Tasks Performed

1. Created a new user account using `useradd`.
2. Set and checked the user's password.
3. Created a new group using `groupadd`.
4. Added a user to a supplementary group using `usermod`.
5. Created a shared directory for the IT support group.
6. Configured directory ownership and permissions using `chown` and `chmod`.
7. Tested directory access using `sudo -u`.

## Commands Used

| Command | Purpose |
|---|---|
| `useradd` | Creates a user |
| `passwd` | Sets or changes a password |
| `groupadd` | Creates a group |
| `usermod` | Modifies user accounts |
| `id` | Displays user and group IDs |
| `chown` | Changes file ownership |
| `chmod` | Changes file permissions |
| `mkdir` | Creates a directory |
| `sudo -u` | Executes a command as another user |

## Skills Practiced

- Linux user administration
- Group management
- Password management
- File ownership
- Access control and permissions
- Basic Linux troubleshooting

## PL

# Zarządzanie użytkownikami i grupami w systemie Linux

## Cel
Ćwiczenie z zakresu administracji użytkownikami i grupami w systemie Linux, zarządzania kontami oraz uprawnieniami dostępu.

## Wykonane zadania

1. Utworzono nowe konto użytkownika za pomocą polecenia `useradd`.
2. Ustawiono i zweryfikowano hasło użytkownika.
3. Utworzono nową grupę za pomocą polecenia `groupadd`.
4. Dodano użytkownika do grupy dodatkowej za pomocą polecenia `usermod`.
5. Utworzono współdzielony katalog dla grupy wsparcia IT.
6. Skonfigurowano własność oraz uprawnienia do katalogu za pomocą poleceń `chown` i `chmod`.
7. Przetestowano dostęp do katalogu przy użyciu polecenia `sudo -u`.

## Użyte polecenia

| Polecenie | Przeznaczenie |
|---|---|
| `useradd` | Tworzy użytkownika |
| `passwd` | Ustawia lub zmienia hasło |
| `groupadd` | Tworzy grupę |
| `usermod` | Modyfikuje konta użytkowników |
| `id` | Wyświetla identyfikatory użytkownika i grupy |
| `chown` | Zmienia właściciela pliku |
| `chmod` | Zmienia uprawnienia do pliku |
| `mkdir` | Tworzy katalog |
| `sudo -u` | Wykonuje polecenie jako inny użytkownik |

## Nabyte umiejętności

- Administracja użytkownikami w systemie Linux
- Zarządzanie grupami
- Zarządzanie hasłami
- Zarządzanie uprawnieniami dla pliku
- Kontrola dostępu i uprawnienia
- Podstawowe rozwiązywanie problemów w systemie Linux
