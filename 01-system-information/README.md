### EN

## System Information and Monitoring

Objective

The purpose of this exercise is to learn how to collect basic system information and monitor Linux resources using terminal commands.

Environment

OS: Fedora Linux

Shell: Bash

Commands and Explanations

| Command | Description |
|---|---|
| `whoami` | Displays the current username |
| `id` | Displays user ID and group memberships |
| `hostnamectl` | Displays system information |
| `uname -a` | Displays kernel information |
| `ip addr` | Displays network interfaces and IP addresses |
| `ip route` | Displays routing table |
| `df -h` | Displays disk space usage |
| `free -h` | Displays RAM usage |
| `uptime` | Displays system uptime |

Practical Results

What I Learned

How to identify the current user and its permissions.

How to retrieve operating system and kernel information.

How to inspect network interfaces and routing.

How to monitor disk space and memory usage.

How to perform basic Linux system diagnostics.

### PL

## Informacje o systemie i jego monitorowanie

Cel

Celem tego ćwiczenia jest opanowanie sposobu zbierania podstawowych informacji o systemie oraz monitorowania zasobów w systemie Linux za pomocą poleceń.

Środowisko

System operacyjny: Fedora Linux

Shell: Bash

Polecenia i wyjaśnienia

| Polecenie | Opis |
|---|---|
| `whoami` | Wyświetla nazwę bieżącego użytkownika |
| `id` | Wyświetla identyfikator użytkownika (UID) oraz przynależność do grup |
| `hostnamectl` | Wyświetla informacje o systemie |
| `uname -a` | Wyświetla informacje o jądrze systemu |
| `ip addr` | Wyświetla interfejsy sieciowe i adresy IP |
| `ip route` | Wyświetla tablicę routingu |
| `df -h` | Wyświetla wykorzystanie przestrzeni dysku |
| `free -h` | Wyświetla wykorzystanie pamięci RAM |
| `uptime` | Wyświetla czas pracy systemu (od momentu uruchomienia) |

Wyniki praktyczne

Czego się nauczyłem

Jak zidentyfikować bieżącego użytkownika oraz jego uprawnienia.

Jak uzyskać informacje o systemie operacyjnym i jądrze systemu.

Jak sprawdzać interfejsy sieciowe oraz konfigurację routingu.

Jak monitorować wykorzystanie przestrzeni dysku i pamięci.

Jak przeprowadzać podstawową diagnostykę systemu Linux.
